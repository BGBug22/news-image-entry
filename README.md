# World news of 13 November 2026 in one image — make.fun `news-image-01`
A program that writes one editorial illustration to /output/entry.png.
It copies the bundled image (peace talks with a dove, an oil tanker in the Strait of Hormuz under storm clouds, a computer chip and a globe) deterministically, stdlib only. News themes: Ukraine peace talks with Europe joining, Iran/Hormuz tanker incidents, Nvidia CEO resignation, Microsoft 365 outage, Storm Charles in Portugal.
